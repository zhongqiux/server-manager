使用指南

下载、接入、同步、运行

首次配置大约 10 分钟。之后每次实验，只需要第 3、4 步。

  1. 01

    运行程序

    Windows 下载 ServerManager.exe 双击运行；macOS 解压后执行 chmod +x ServerManager && ./ServerManager。浏览器会自动打开本地界面，数据保存在系统应用数据目录。

    免安装单实例重启后数据保留
  2. 02

    添加服务器

    填写地址、端口、用户名，选择密码或私钥认证，点击「测试连接」。确认 TCP、SSH 握手、认证与远程执行四步全绿，硬件与 GPU 快照会自动采集。

    密码加密存储支持 passphrase
  3. 03

    创建项目与 Target

    项目指向本地代码根目录；在项目里添加 Target 绑定一台服务器，填写远程代码目录、数据目录、conda 环境与运行命令。路径差异交给占位符，换机器不用改代码。

    可先预览最终脚本同一项目可绑多台机器
  4. 04

    检查差异，同步并运行

    先点「检查差异」查看 dry-run 计划，确认后开始增量同步。在运行区选择新建独立会话，或使用已有 tmux / screen 会话的新窗口；启动后进入任务详情看实时日志。

    运行前可自动同步停止不会关闭已有会话

首次运行提示

Windows 提示“未知发布者”

exe 未做代码签名。点击「更多信息 → 仍要运行」即可；分发时可附带 SHA256 供校验。

macOS 首次打开被拦截

包为 ad-hoc 签名、未公证。右键选择“打开”，或在终端执行 xattr -dr com.apple.quarantine ServerManager。

没有服务器，也想先看看

Windows：set SM_DEMO=1 && ServerManager.exe；macOS：SM_DEMO=1 ./ServerManager。会载入合成的服务器、GPU 与任务数据。

U 盘或便携使用

使用 --portable，数据会写在可执行文件同目录的 data/，连同程序一起带走。

常见问题

你可能想先确认的事

会不会把我的代码、密码或日志传到别的地方？

不会。应用只监听本机的 127.0.0.1，所有 SSH / SFTP / Git 操作都由你的电脑直接连接你的服务器。服务器密码与私钥使用 AES-256-GCM 加密后保存在本地数据目录，界面只显示“已保存”，不会回显明文。项目没有账号体系，也没有云端中转。

对远程服务器有什么要求？

需要一台能 SSH 登录的 Linux 服务器，默认 shell 为 bash。推荐安装 tmux 或 screen（都没有时会退化为 nohup 后台进程）；nvidia-smi 与 git 都是可选项。首次连接会自动探测 find、stat、tail 等命令的能力，老系统会自动降级兼容。

和直接用 rsync / scp 有什么区别？

传输前会给出 dry-run 计划，明确列出新增、更新、删除与被忽略的文件；写入使用临时文件 + rename 原子替换并保留 mtime；镜像删除默认关闭，开启后也需要输入目标名二次确认。还支持 A→B 中转同步，以及可选的 Git 中心仓库模式；Git 模式不会 force push，目标机工作区脏时零写入并中止。

断网或关掉软件，任务会停吗？

不会。任务运行在远程的 tmux / screen 会话或 nohup 后台进程中，SSH 断开不会影响它。重新打开软件后，任务状态与日志会继续同步；日志以字节偏移续传，断线重连不重复、不遗漏。

使用已有 tmux / screen 会话，会不会误关我的会话？

不会主动关闭。默认行为是新建独立会话；选择已有会话时，只会在其中新开一个窗口，或在确认空闲后向已有窗口注入命令。停止任务只清理本工具创建的窗口与进程组，已有会话和窗口保持不变。

数据存放在哪里？换电脑怎么办？

Windows 默认在 %LOCALAPPDATA%\ServerManager\data，macOS 默认在 ~/Library/Application Support/ServerManager/data，包含数据库、密钥与临时文件；使用 --portable 时写在可执行文件同目录的 data/。迁移时复制整个数据目录即可，但请一并保留 keys/，否则已加密的凭据无法解密。

支持 macOS / Linux 吗？

Windows x64 与 macOS（Apple Silicon / Intel）均提供单文件包；macOS 包为 ad-hoc 签名、未公证，首次打开需右键“打开”。Linux 可从源码构建运行。

MCP 是什么？怎么下载？

MCP 是给 AI Agent 调用的可选接口，不是主程序的一部分，日常手动使用不需要它。它需要本地 Node.js 22.18+，并保持主程序在运行。下载 ServerManager-mcp.zip（约 0.1 MB）并解压到任意目录，然后在 MCP 客户端（Qoder / Claude Desktop 等）中注册：

{
  "mcpServers": {
    "server-manager": {
      "command": "node",
      "args": ["/解压目录/ServerManager-mcp/index.js"],
      "env": { "SM_MCP_BASE_URL": "http://127.0.0.1:8787" }
    }
  }
}

重启客户端后即可看到 24 个工具；工具默认 dry-run、只读凭据、不触碰已有会话。完整说明见压缩包内 README。
