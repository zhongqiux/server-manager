你可能想先确认的事

会不会把代码、密码或日志传到别的地方？

不会。应用只监听本机 127.0.0.1，SSH / SFTP / Git 都由你的电脑直连服务器。密码与私钥使用 AES-256-GCM 加密后保存在本地，界面只显示“已保存”，不会回显明文。没有账号体系，也没有云端中转。

对远程服务器有什么要求？

一台能 SSH 登录的 Linux 服务器，默认 shell 为 bash。推荐安装 tmux 或 screen（缺失时退化为 nohup 后台进程）；nvidia-smi 与 git 都是可选项。首次连接会自动探测命令能力，老系统自动降级兼容。

断网或关掉软件，任务会停吗？

不会。任务运行在远端的 tmux / screen 会话或 nohup 后台进程中，SSH 断开不影响它。重新打开软件后，任务状态与日志继续同步；日志以字节偏移续传，不重复、不遗漏。

使用已有 tmux / screen 会话，会误关我的会话吗？

不会主动关闭。默认新建独立会话；选择已有会话时，只会在其中新开窗口，或确认空闲后注入命令。停止任务只清理本工具创建的窗口与进程组。

数据存放在哪里？换电脑怎么办？

Windows 默认在 %LOCALAPPDATA%\ServerManager\data，macOS 在 ~/Library/Application Support/ServerManager/data；--portable 时写在程序同目录。迁移时复制整个数据目录，并保留 keys/，否则已加密的凭据无法解密。

支持 macOS / Linux 吗？

Windows x64 与 macOS（Apple Silicon / Intel）均提供单文件包；macOS 包未公证，首次打开方式见下载区说明。Linux 可从源码构建运行。

MCP 是什么？怎么接给 Agent？

给 AI Agent 调用的可选接口，需要本地 Node.js 22.18+ 且主程序在运行。下载 ServerManager-mcp.zip 解压后，在 Qoder / Claude Desktop 等客户端注册解压目录中的 index.js，完整配置示例见压缩包内 README。工具默认 dry-run、只读凭据、不触碰已有会话。
